تسجيل الدخول

تُحفظ المقالات مباشرة في مستودع الموقع على GitHub، ويُعاد نشر الموقع تلقائيًا خلال دقيقة أو دقيقتين.

كيف أحصل على مفتاح الوصول؟
  1. افتح GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. اختر Only select repositories وحدد مستودع الموقع فقط.
  3. من Repository permissions اجعل Contents = Read and write.
  4. انسخ المفتاح والصقه هنا. يمكنك إلغاؤه من GitHub في أي وقت.
