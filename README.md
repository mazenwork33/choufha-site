# موقع Choufha — choufha.com

موقع ثابت بالعربية والإنجليزية. يُبنى تلقائيًا على GitHub Pages، وفيه لوحة لإضافة المقالات على `/admin`.

## التشغيل لأول مرة

1. **أنشئ مستودعًا جديدًا عامًا (Public)** على GitHub، باسم `choufha-site` مثلًا، ثم ارفع إليه كل محتويات هذا المجلد.
   - Pages مجانية للمستودعات العامة.
   - مفتاح الدخول لا يُحفظ داخل المستودع، فلا خطر من أن يكون المستودع عامًا.
2. **فعّل النشر:**
   - افتح Settings ← Pages ← Build and deployment، واختر **Source = GitHub Actions**.
   - افتح تبويب Actions وانتظر حتى تظهر علامة ✅ على «Build & deploy site». يستغرق ذلك دقيقة تقريبًا.
3. **اربط الدومين:**
   - في Settings ← Pages ← Custom domain اكتب `choufha.com` ثم اضغط Save.
   - من Cloudflare ← choufha.com ← DNS ← Records أضف السجلات التالية، واجعل **Proxy status = DNS only (السحابة رمادية)**:

   | النوع | الاسم | القيمة |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `mazenwork33.github.io` |

   - بعد أن يتفعّل الدومين (عادةً دقائق مع Cloudflare)، فعّل **Enforce HTTPS** في GitHub.
   - احذف أي سجلات A أو AAAA قديمة لـ `@` أو `www` أضافتها Cloudflare تلقائيًا.
4. **اختبر الموقع من شبكة مصرية بدون VPN**، على الموبايل وعلى اللابتوب.

## إضافة مقال

1. افتح `https://choufha.com/admin/`.
2. أدخل:
   - اسم المستودع، مثل `mazenwork33/choufha-site`.
   - الفرع `main`.
   - مفتاح وصول (Fine-grained token). الخطوات مكتوبة داخل صفحة الدخول.
3. اضغط «مقال جديد»، واكتب المقال، ثم اضغط «حفظ ونشر». يظهر المقال على الموقع خلال دقيقة أو دقيقتين.

كل مقال يحصل تلقائيًا على:
- صفحة مستقلة.
- بيانات SEO وبيانات المشاركة (OG).
- مكان في خريطة الموقع `sitemap.xml` وفي RSS.

## تعديل البيانات الثابتة

كل البيانات الثابتة في ملف **`config.json`**:
- البريد.
- الهاتف (فارغ الآن، ويظهر بجانبه «يُعلن قريبًا»).
- واتساب. يظهر زر عائم بمجرد إضافة الرقم.
- روابط السوشيال ميديا. لإخفاء منصة، اترك قيمتها فارغة `""`.

بعد التعديل والحفظ على GitHub، يُعاد بناء الموقع تلقائيًا.

## تعديل النصوص

- نصوص الموقع كلها، عربي وإنجليزي: `src/i18n.mjs`.
- سياسة الخصوصية والشروط: `content/pages/`.

## للمطوّر

- `npm install` ثم `npm run build` لبناء الموقع في `dist/`.
- `npm run bundle` لإعادة تجميع مشهد الـ 3D (`src/hero3d.js`).
- مجسم الـ 3D في الواجهة موجود في `static/assets/models/sofa.glb`.
  - يمكن استبداله بأي ملف GLB لقطعة من عميل.
  - تأكد أن اسم خامة القماش `Fabric` حتى تعمل خاصية تغيير اللون.
